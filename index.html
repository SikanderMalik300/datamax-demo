    About this demo

    A working prototype of a searchable literature reference for Alveolar Rhabdomyosarcoma (ARMS), built to show the quality of the interface and the data model before building the full product.

    What this is

    • 35 real, PMID-verified papers — every record links to its genuine PubMed entry.
    • Each paper tagged across three linked layers: fusion, gene, pathway.
    • A plain-language summary of each paper's key finding.
    • A pathway view that links any pathway back to PAX3::FOXO1.

    How the product is built

    1. 01 Harvest papers from PubMed / Europe PMC
    2. 02 Tag each paper by fusion, gene & pathway
    3. 03 Store in a searchable database
    4. 04 This interface queries that database

    In this demo the data is a curated export, so it runs entirely in the browser — no server — and hosts on GitHub Pages.

    Roadmap

    Stage 1 this demo
    ARMS papers, tagged by fusion & gene, fully searchable, with pathway links. Starts with PAX3::FOXO1, structured for every fusion.
    Stage 2 next
    Pull in papers from other cancers and general cell biology for each pathway as new linked layers. Nothing is rebuilt — a new pathway is new data.
    Stage 3
    Connect expression datasets (GEO / TCGA-style) and build models on the organised data.

    Demonstration prototype for research-workflow evaluation only — not a medical or clinical decision tool. Summaries are concise paraphrases; always consult the linked primary source.
