About this demo

A working prototype of a searchable literature database for Alveolar Rhabdomyosarcoma (ARMS), built to show the quality of the interface and the underlying data model before building the full product.

What you're looking at

  • 35 real, PMID-verified papers — every record links to its genuine PubMed entry.
  • Each paper is tagged by fusion, gene and pathway — three separate, linked layers.
  • A plain-language AI-style summary of each paper's key finding.
  • A Pathway Explorer that links any pathway back to PAX3::FOXO1.

How the real product is built

  1. 1 Harvest papers from PubMed / Europe PMC
  2. 2 AI tags each paper by fusion, gene & pathway
  3. 3 Store in a searchable database
  4. 4 This interface queries that database

In this demo the data is a hand-curated export so it can run entirely in the browser (no server) and be hosted on GitHub Pages.

Roadmap

Stage 1 — this demo

ARMS papers, tagged by fusion & gene, fully searchable, with pathway links. Starting with PAX3::FOXO1, structured for every fusion.

Stage 2 — pathway expansion

Pull in papers from other cancers and general cell biology for each pathway (PI3K/AKT/mTOR, Hippo/YAP1, Wnt, Notch, CDK4/6 …) as new linked layers. Nothing is rebuilt — a new pathway is just new data.

Stage 3 — data & modelling

Connect expression datasets (GEO / TCGA-style) and build models on the organised data.

⚠️ Demonstration prototype for research workflow evaluation only — not a medical or clinical decision tool. Paper summaries are concise paraphrases; always consult the linked primary source.
